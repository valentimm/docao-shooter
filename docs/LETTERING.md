# Lettering das placas

Artes transparentes geradas com a ferramenta nativa image_gen, usando o alfabeto aprovado como referência visual. São PNGs de palavras, não uma fonte WOFF2/TTF.

## ARSENAL

Arquivo: `lettering-arsenal.png`.

### Prompt usado

Create an isolated lettering PNG asset for the existing Docão Shooter game menu. Use the supplied alphabet ONLY as a reference for the SHAPES of the letters. IMPORTANT COLOR OVERRIDE: warm ivory cream (#f4d6a0) faces with subtle muted brown edges, matching cream lettering on a wooden crate; NO YELLOW OR GOLD. Do not copy the yellow from the reference. Match the same thick irregular chunky broad letters, soft slab details, handcrafted carved wood silhouette and very subtle texture. Use only a shallow restrained relief, clean crisp contours and clear readable counters optimized for a small button. Spell EXACTLY "ARSENAL", no extra words. Layout: single horizontal line of text, wide short landscape canvas. The text must fill 94 percent of the image width with narrow transparent margins. GENUINE TRANSPARENT BACKGROUND, no flat backdrop, no wooden plaque, no frame, no icon, no animal, no caption, no alphabet. Only the letters. No heavy shadows or strong glossy bevels, no gold highlights. Keep strong contrast and clean silhouettes. Preserve the character of the reference alphabet while respecting the required text color.
